
# Описание сущностей информационной системы сети ресторанов «Ромашка»

| Наименование сущности | Описание | Связи с другими сущностями |
| :--- | :--- | :--- |
| **Единица измерения** | Мера веса, объема или штучного учета (кг, л, шт, порция). | Номенклатура (1:N), Группа категорий (N:1) |
| **Деньги** | Стоимость или сумма платежа с фиксацией валюты. | Блюдо (1:1), Контракт (1:N), Платежный документ (1:1) |
| **Адрес** | Географическое положение филиала, склада или точки доставки. | Ресторан (1:1), Склад (N:1), Зона доставки (N:1), Заказ (1:N) |
| **Группа** | Иерархический классификатор (группа единиц измерения, контрагентов). | Номенклатура (1:N), Контрагент (1:N), Группа-родитель (1:N) |
| **Контрагент** | Юридическое лицо или поставщик сырья. | Группа (N:1), Контракт (1:N), Платежный документ (1:N) |
| **Категория персонала** | Профиль работы сотрудника (производство, сервис, управление). | Сотрудник (1:N), График работы (1:N) |
| **Зона доставки** | Городской сектор с закрепленным тарифом доставки. | Ресторан (N:M), Заказ (1:N), Адрес (1:N) |
| **Сотрудник** | Работник сети ресторанов с защитой от удаления при наличии движений. | Ресторан (N:1), Категория персонала (N:1), График работы (1:N), Документы учета (1:N) |
| **Ингредиент / Позиция состава** | Сырье с указанием массы/объема и ссылкой на единицу измерения. | Номенклатура (N:1), Единица измерения (N:1), Технологическая карта (N:1) |
| **Строка заказа** | Элемент клиентского заказа с количеством, ценой и тарой. | Заказ (N:1), Блюдо (N:1), Упаковка (N:1) |
| **Номенклатура** | Каталог сырья, заготовок, блюд и сопутствующих товаров. | Группа (N:1), Единица измерения (N:1), Складской остаток (1:N), Ингредиент (1:N) |
| **Блюдо / Номенклатура блюд** | Позиция меню с установленной ценой, техкартой и обязательной тарой. | Номенклатура (1:1), Технологическая карта (1:1), Строка заказа (1:N) |
| **Упаковка** | Упаковочный материал, закрепляемый за блюдом при доставке. | Номенклатура (1:1), Блюдо (N:M), Строка заказа (1:N) |
| **Технологическая карта** | Спецификация блюда: раскладка ингредиентов, граммовка и этапы. | Блюдо (1:1), Ингредиент (1:N), Вложенная техкарта (1:N), Производственный выпуск (1:N) |
| **Склад** | Хранилище остатков сырья и заготовок (включая производственный цех). | Ресторан (N:1), Адрес (1:1), Складской остаток (1:N), Инвентаризация (1:N) |
| **Складской остаток** | Регистр фактического количества номенклатуры на конкретном складе. | Склад (N:1), Номенклатура (N:1), Производственный выпуск (N:1) |
| **Ресторан (Company / Точка)** | Точка сети (зал, доставка, комбинированный формат или цех). | Адрес (1:1), Склад (1:N), Сотрудник (1:N), Зона доставки (M:N), Заказ (1:N) |
| **Контракт** | Документ-соглашение с контрагентом на регулярную или разовую закупку. | Контрагент (N:1), Сотрудник (N:1), Платежный документ (1:N) |
| **График работы** | Расписание смен с расчетом переработок по двойному тарифу. | Сотрудник (N:1), Категория персонала (N:1) |
| **Производственный выпуск** | Документ выпуска продукции (списание с блокировкой или под сальдо). | Технологическая карта (N:1), Склад списания (N:1), Склад поступления (N:1), Сотрудник (N:1) |
| **Инвентаризационная ведомость** | Документ ревизии фактических остатков (полная или по категории). | Склад (N:1), Группа (N:1), Сотрудник (N:1) |
| **Заказ** | Сквозной процесс: клиент → кухня (блюда) → склад → адрес доставки. | Ресторан (N:1), Зона доставки (N:1), Адрес (N:1), Строка заказа (1:N), Сотрудник (N:1) |
| **Заявка на перемещение** | Требование ресторана на подвоз заготовок из центрального цеха. | Ресторан-заказчик (N:1), Цех-отправитель (N:1), Сотрудник (N:1) |
| **Платежный документ** | Документ учета движения денежных средств (приход / расход, нал / безнал). | Денежная сумма (1:1), Контрагент (N:1), Договор (N:1), Сотрудник (N:1) |
| **Помещение** | Физическая зона ресторана или цеха (холодильная камера, склад, кухня, зал). | Ресторан (N:1), Склад (1:1) |
| **Партия сырья** | Поставка сырья с контролем даты выработки и срока годности. | Номенклатура (N:1), Склад (N:1), Договор поставки (N:1) |
| **Акт списания / утилизации** | Документ выбытия испорченного сырья, полуфабрикатов или брака. | Склад (N:1), Номенклатура (1:N), Сотрудник (N:1) |
| **Строка инвентаризации** | Позиция ведомости: учетный остаток, фактический остаток и расхождение. | Инвентаризационная ведомость (N:1), Номенклатура (N:1) |
| **Меню доставки** | Ограниченный перечень блюд сети с тарой, доступных для заказа курьером. | Блюдо (N:M), Ресторан (N:1) |
| **Курьер** | Профиль сотрудника доставки со статусом занятости и привязкой к району. | Сотрудник (1:1), Зона доставки (N:M), Заказ на доставку (1:N) |
| **Маршрутный лист** | Наряд-лист со списком сгруппированных заказов и временем доставки. | Курьер (N:1), Ресторан (N:1), Заказ на доставку (1:N) |
| **Способ оплаты** | Метод расчета (наличные при получении, банковская карта, безналичный перевод). | Платежный документ (1:N), Заказ на доставку (1:N) |
| **Акт сверки расчетов** | Ведомость взаиморасчетов и сальдо задолженности с контрагентом. | Контрагент (N:1), Договор поставки (N:1), Платежный документ (1:N) |
| **Тарифная ставка** | Базовый расчетный тариф оплаты труда для начисления двойной ставки за переработку. | Категория персонала (N:1), Сотрудник (1:1) |
| **Табель учета времени** | Месячный свод отработанных базовых часов и часов переработки. | Сотрудник (N:1), Рабочая смена (1:N), Ресторан (N:1) |
| **Заказ на производство** | Плановое задание цеху на выпуск партии заготовок или полуфабрикатов. | Производственный цех (N:1), Номенклатура (1:N), Производственный выпуск (1:N), Сотрудник (N:1) |
| **Полуфабрикат** | Заготовка центрального цеха, используемая ресторанами для приготовления конечных блюд. | Номенклатура (1:1), Технологическая карта (1:1), Заявка на перемещение (1:N) |
| **Складское движение** | Операция прихода, расхода или списания (с блокировкой остатка или под сальдо). | Склад (N:1), Номенклатура (N:1), Складской остаток (N:1), Производственный выпуск (N:1) |
| **Режим работы подразделения** | График функционирования объекта сети (10:00–22:00 для ресторанов, круглосуточно для цеха). | Ресторан (1:1), Рабочая смена (1:N) |
| **Касса / Расчетный счет** | Место учета наличных денежных средств ресторана или банковского счета компании. | Ресторан (N:1), Денежная сумма (1:1), Платежный документ (1:N) |
